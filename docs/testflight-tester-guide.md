# TestFlight Tester Guide

## Goal

Find anything that blocks a parent from creating useful practice or a child from completing it without confusion.

## Install

- Install Apple's TestFlight app from the App Store.
- Accept the Skeelio invite.
- Install the latest Skeelio build.

## Main Smoke Test

1. Sign in or create the test parent account.
2. Add or select a child.
3. Scan a worksheet.
4. Assign generated practice to the child.
5. Open the child home page.
6. Complete the assignment as the child.
7. Check that the parent dashboard records the work.

## What To Watch For

- Camera permission problems.
- Upload or scan failures.
- Questions that do not match the worksheet.
- Repeated or oddly ordered questions.
- Wrong-answer feedback that does not show the child's answer.
- Completion returning to the wrong page.
- Parent dashboard missing completed work.
- Screens that feel visually inconsistent or hard to understand.

## Helpful Feedback

For each issue, capture:

- Screenshot or screen recording.
- What you expected.
- What happened.
- Steps to reproduce.
- Child/assignment involved, if relevant.

## Current Known Rough Edges

- Parent dashboard clarity is still early.
- The star shop is a placeholder.
- Parent-created objectives are not yet implemented as a complete planning flow.
- External TestFlight testers may require Apple beta review before access.
